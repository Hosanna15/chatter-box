## ✨ Extraordinary Features

This isn't just a simple chat app. It's a demonstration of a professional, end-to-end development workflow with advanced features:

-   **Real-Time Communication:** Instant message delivery and user presence updates powered by **Socket.IO**.
-   **Persistent Chat History:** All messages are saved to a **MongoDB** database, so conversations are never lost on refresh.
-   **Dynamic User Presence:** A live sidebar shows a list of all users currently online in the chat room, complete with avatars.
-   **Rich User Experience:**
    -   **Emoji Picker:** Users can add emojis to their messages.
    -   **User Avatars:** Automatically generated, colorful avatars for each user.
    -   **Smooth Animations:** Messages appear with subtle animations using **Framer Motion** for a premium feel.
-   **Colorful & Responsive UI:** A stunning, modern interface with an animated gradient login screen and a sleek, dark-themed chat window that works beautifully on all devices.
-   **System Messages:** Automatic notifications when a user joins or leaves the chat.

## ⚙️ Getting Started

To get a local copy of this project up and running, follow these steps.

### Prerequisites

-   Node.js & npm installed: [Download Node.js](https://nodejs.org/en/)
-   A MongoDB Atlas account: [Create a free account](https://www.mongodb.com/cloud/atlas/register)


### Running the Application

1.  **Start the Backend Server:**
    -   From the `backend` directory, run:
        ```sh
        npm start
        ```
    -   The server will start on `http://localhost:5000`.

2.  **Start the Frontend Client:**
    -   From the `frontend` directory, run:
        ```sh
        npm start
        ```
    -   The application will automatically open in your browser at `http://localhost:3000`.
