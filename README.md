# 💬 ChatterBox – Real-Time Chat Application

**ChatterBox** is a full-stack, real-time messaging application built with the MERN stack and Socket.IO. It delivers instant communication through a modern, responsive interface while showcasing real-time technologies, persistent data storage, and an engaging user experience.

---

## 🌐 Live Demo

🔗 **Try it here:** https://chatterbox-app-dusky.vercel.app/

---

## ✨ Features

* ⚡ **Real-Time Messaging** – Send and receive messages instantly using Socket.IO.
* 💾 **Persistent Chat History** – Conversations are securely stored in MongoDB and remain available after page refreshes.
* 🟢 **Live User Presence** – View users who are currently online with automatically generated avatars.
* 😀 **Emoji Support** – Express yourself with an integrated emoji picker.
* 🎨 **Modern & Responsive UI** – Clean interface featuring glassmorphism, smooth animations, and a fully responsive design.
* ✨ **Smooth Animations** – Enhanced user interactions powered by Framer Motion.
* 🔔 **System Notifications** – Automatic join and leave notifications for active users.
